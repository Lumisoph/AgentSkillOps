# AgentSkillOps 复现指南

## 环境

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -e ".[analysis,dev]"
```

核心模块与三个自检只使用 Python 标准库。`analysis` 额外依赖用于精确二项置信区间。

## 快速验证

```bash
pytest
python experiments/selfcheck_freshness.py
python experiments/selfcheck_lifecycle.py
python experiments/selfcheck_stage57.py
```

这些检查覆盖效用方差、时间线查询、连续确认、无数据保留、状态空间恒等式、参数恢复、
READMIT 和成本比映射。

## 复算公开结果

### 可靠性审计

```bash
python experiments/reliability_audit.py \
  --mode audit \
  --timeline results/stage55_measure/utility_store_timeline_5pt.json \
  --out results/stage57_reliability
```

### 轨迹可识别性

```bash
python experiments/fit_trajectories.py \
  --timeline 3pt=results/stage55_measure/utility_store_timeline.json \
  --timeline 5pt=results/stage55_measure/utility_store_timeline_5pt.json \
  --out results/stage57_e2
```

### 2×2 因子分解

```bash
python experiments/analyze_factorial.py \
  --out results/stage57_factorial/factorial_ckpt40.json
```

脚本默认读取 `none / general_only / task_specific_only / full` 四份同行配对 CSV，并固定
bootstrap 随机种子。

### 独立任务验证

```bash
python experiments/analyze_p2.py \
  --out results/stage57_p2/p2_valid_unseen.json

python experiments/analyze_p1.py
```

P2 检查五种技能激活条件在 134 个 OOD 任务上的成功率、非劣界和 token 成本；P1 在另一
checkpoint 的 200 个任务上检查 TS Only 的适用边界。

## 数据说明

`results/` 中提交的是分析所需的最小数据：每个 episode 的汇总行、效用时间线和机器可读结果。
以下内容被明确排除：

- 模型权重和 checkpoint；
- ALFWorld 数据集与环境副本；
- 逐步思维/交互轨迹；
- 训练日志、缓存和第三方框架源码。

因此仓库可以复算公开的统计分析，但不能独立重新执行大模型 rollout。重新生成 rollout 需要按
上游 SkillRL 文档准备环境和模型，再以相同任务顺序、随机种子和技能条件导出同结构 CSV。
